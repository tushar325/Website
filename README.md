# Coffee Shop WordPress Theme

This workspace contains a lightweight WordPress theme for a modern coffee-selling website.

## What is included
- Responsive, modern landing page
- Lightweight custom theme named Coffee Light
- Dynamic product section for coffee items that admins can manage
- Dynamic post section for coffee stories and menu highlights
- Simple navigation and footer

## Next steps
1. Install WordPress in this folder or place these files into an existing WordPress installation.
2. In the WordPress admin panel, go to Appearance > Themes and activate Coffee Light.
3. Go to Products in the admin sidebar and add new coffee products.
4. For each product, add a title, description, image, and a price in the Product Price field.
5. Create a few posts and set a site title and logo.
6. Optionally install a caching plugin and a lightweight image optimization plugin for better performance.
